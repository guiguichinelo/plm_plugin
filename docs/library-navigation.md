# Library navigation and scoped personal lists

Beta 11 targets Jellyfin web/server 12.4.0. Movies and series libraries receive visible All, Suggestions, Genres and Favorites links. Existing native suggestions, genre views, sorting, filters and catalog pagination remain native. Other movie/series views remain accessible through More. Native movie Favorites entries are redirected to PLM for the same library.

Library Favorites shows content shelves: Liked first, then Watch Later and personal lists. Only nonempty shelves for the current library are displayed. Each shelf samples at most ten titles; up to six shelves are loaded at a time, with More lists for the next page. Preview items are hydrated in one batch. Clicking a shelf heading opens the complete list with search, searchable multiple genres, advanced filters and pagination. The overview has no filter toolbar or separate Explore button. All saved remains available as a deduplicated union in global Favorites. List membership never changes native favorite state. Collections remain shared across the user's own views; opening a library changes only which selections are displayed.

Scoped views use native portrait-card widths, card boxes and section headings, with scroll buttons above the row as in Genres. They do not use global Favorites cover artwork, sidebar or management controls. The library backdrop is preserved when entering from a native view, or obtained from an authorized item with an actual backdrop. Poster images are never stretched into backdrop replacements. A per-owner/library cache keeps the same scene while opening a list or returning to its overview; host backdrop filters are inherited. Empty libraries show an explanatory message and a Browse library link. Filtered empty results inside complete lists retain the filters and offer a reset. Genres are derived from visible titles in the current source and library, rather than the whole server. Global Favorites retains list management and its existing presentation.

The web host can cache several instances of the same plugin template. Each instance initializes independently; the surface coordinator resumes the visible instance and ignores stale requests from inactive views. Regression tests cover separate cached instances, returning to an earlier instance and empty-to-populated transitions.

The optional `libraryId` filter is applied on the server before pagination and counts, including grouped/custom-order collection pages. The root must be a visible CollectionFolder. Invalid identifiers are rejected and hidden/unknown roots return 404. All queries retain Jellyfin's user context and content restrictions. The union shows visible catalogued items; unavailable selections remain preserved and removable through individual lists without a library filter.

Implementation detail: `Folder.GetItems` directly queries ItemIds without inferring its parent. Therefore PLM explicitly sets InternalItemsQuery.Parent before querying; it does not rely on invoking GetItems on the folder instance. This was verified against the [host source matching NuGet 12.4.0](https://github.com/jellyfin/jellyfin/blob/83d0d0e7f76e23e2e085c8ff67d28b772d35967d/MediaBrowser.Controller/Entities/Folder.cs) and a live test using two libraries containing the same media type.

The last main view is remembered per server, user and library in browser local storage. It is not synchronized between devices. Explicit native tab URLs override the remembered choice. Moving between library/global contexts clears transient list filters to avoid accidentally carrying an unrelated genre/type into another library.

The native view selector is deliberately hidden when the enhanced navigation is present. Navigation updates therefore locate its visible toolbar, rather than requiring the hidden selector itself to be visible. This keeps the highlighted tab, asynchronously loaded library name, history navigation and More options synchronized after the first render. Tests explicitly verify active tabs while the native selector remains hidden.

Details-page Watch Later buttons copy the rendered dimensions and icon font size from the adjacent native favorite button, including after resize. The clock retains its own lifecycle and does not inherit native rating/playstate selectors. Card controls retain their independent sizing.

The interface inherits the installed theme. No installed web bundle is patched. Script/style cache versions are updated with the candidate. New native labels are sourced from Jellyfin's translations; custom labels have Portuguese/English translations with English fallback. Other clients, library types and future web DOM revisions need separate validation.

Regression coverage: API tests check owner/library scope, union deduplication, version aliases, pagination, unchanged source lists, invalid roots and restricted access. Browser tests cover native view URLs, toolbar cleanup, scoped list/liked queries, view memory isolation and clock sizing/native refresh behavior.
