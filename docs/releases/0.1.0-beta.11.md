# PLM 0.1.0-beta.11

Expose All, Suggestions, Genres and Favorites in movie/series library navigation. Library Favorites presents Liked, Watch Later and personal lists as content shelves filtered to that library. Click a section heading to open its full list with search, contextual genres, filters and pagination. The overview follows Genres-style card dimensions and headings, keeps its library backdrop, and omits filters and separate Explore buttons. Empty shelves are omitted; empty libraries and filters have explicit recovery actions. Global Favorites retains its management interface. Existing collections remain unchanged, and list membership does not create native likes.

Initialize and resume multiple cached plugin pages independently, preventing blank or uninitialized views when returning from native library routes. Scoped pages preserve library backdrops with the installed theme's image treatment, instead of using global Favorites cover artwork.

Keep library headings and active tabs synchronized when switching native views, returning from Favorites or using browser history. The enhanced toolbar remains discoverable after its native selector is hidden.

Apply the optional library filter on the server before pagination and version-group presentation. Validate visible library roots and retain the requesting user's content restrictions. Add a read-only saved union with duplicate/version grouping. Remember the main view per server/user/library in the current browser.

Match the details-page Watch Later clock to the adjacent native favorite icon and button dimensions, including resizing and installed-theme styling. Preserve the clock's independent lifecycle during metadata refreshes. Retain the beta 10 legacy TV Favorites navigation fix.

No database migration. Targets Jellyfin 12.4.0 / Linux x64 with matching Plugin Pages and File Transformation dependencies. Library integration targets movie/series CollectionFolder roots and the 12.4 web interface; other library types, grouped UserViews, other clients and physical TV remote navigation require separate validation. Native labels reuse host translations; custom text uses Portuguese/English with English fallback.
