# PLM 0.1.0-beta.1

First public beta of Jellyfin Personal Library Manager, distributed through
[Betterfin's Jellyfin 12 catalog](https://raw.githubusercontent.com/guiguichinelo/betterfin/main/12/manifest.json).

This build targets **Jellyfin 12.4.0 on Linux x64**. It is a prerelease; other
server versions and architectures are not validated. The catalog/assembly version
is `0.1.0.1`, while the release tag is `v0.1.0-beta.1`.

Features:

- A unified Favorites page with native Liked content, Watch Later and private lists.
- Heart-based list selection and an independent Watch Later clock.
- Private thumbnails, contextual rename/delete actions, trash and restore.
- Server pagination, title search, multiple searchable genres and browse filters.
- Watch Later after Next Up, with user-specific progress and visibility checks.
- User export/import and administrator database backup/maintenance.
- Theme-aware controls and cached-page backdrop lifecycle handling.
- Interface preference support for the target release's 64 locales. Plugin-specific
  translations remain partial outside English/Portuguese and fall back to English.

Before installing, back up Jellyfin configuration and PLM data. Install **Plugin
Pages 3.0.3.0 and File Transformation 3.0.3.0, Release-12.4.0 builds**, then add
Betterfin's catalog or extract the attached Linux x64 package with Jellyfin stopped.
Wait for Plugin Pages startup and reload the web client after restarting.
Do not keep two PLM versions enabled; let the catalog handle upgrades or move the
previous plugin directory outside the plugins directory during a manual upgrade.
Keep every DLL and the native SQLite library from the ZIP together.

The plugin does not delete original media. Private-list data remains in
`<Jellyfin DataPath>/plm/plm.db`; uninstalling the assembly preserves it. Optional
native playlist mirrors are disabled by default and remain experimental.

Validation: 15 core and 10 HTTP tests; both browser suites, including all 64
locale options, owner privacy, list actions, pagination and navigation regressions.
The preceding build was exercised on real Jellyfin 12.4.0 Linux x64. Native-client
playback, sustained load, other architectures and future Jellyfin releases remain
outside this beta's validated scope. Consult repository Actions for this commit's CI.

The ZIP includes license notices. SHA256SUMS.txt and the JSON build receipt identify
the exact published bytes; the catalog's required checksum field uses MD5.
