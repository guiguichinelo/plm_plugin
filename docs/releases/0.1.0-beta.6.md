# PLM beta 6

Fix HTTP 500 when another plugin passes an empty GUID to clear a selection, and allow independent native user-data updates to proceed concurrently. Mirror reads remain owner-scoped, and native playlist mutations retain their protection and creation/recovery barrier.

Targets Jellyfin 12.4.0 on Linux x64. Requires compatible Plugin Pages and File Transformation builds. Catalog resilience, Favorites presentation, translations and the existing database schema are unchanged.

The concurrency exception applies only to the Jellyfin 12.4 UserData controller's UpdateItemUserData action. It does not remove the mutation gate from other endpoints, and it does not bypass mirror ownership checks. HTTP tests cover concurrent progress, cross-owner denial, empty selection sentinels and mixed bulk operations.

Back up Jellyfin, PLM data and plugin binaries before updating. Assembly version is 0.1.0.6; earlier release archives remain immutable. This change alone is not a streaming-capacity or database-performance certification.
