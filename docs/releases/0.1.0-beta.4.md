# PLM beta 4

Restrict full-width responsive layout to the Favorites library. Personal settings keep their original centered width, and host pages are unaffected. Retains beta 3's localized Favorites settings heading, native create-list/trash controls, active navigation and browser-title fixes.

Targets Jellyfin 12.4.0 on Linux x64. Requires matching Plugin Pages and File Transformation 3.0.3.0 Release-12.4.0 builds. Incomplete translations use the documented English fallback. There are no database schema or content changes. Earlier beta archives remain immutable.
