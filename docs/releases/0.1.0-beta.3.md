# PLM beta 3

Clarify personal collection management with a localized Favorites settings heading and remove the redundant Personal preferences eyebrow. Keep Favorites navigation selected on PLM routes and synchronize the browser tab title with the active page and interface language.

The settings heading has English/Portuguese and additional full-phrase translations. Other interface locales reuse Jellyfin's localized Settings and Favorites labels where available; incomplete host dictionaries retain the documented English fallback. Create-list and trash controls now use Jellyfin's native icon-button treatment, with transparent resting surfaces and inherited theme interactions. Existing personal lists, likes, memberships and stored data are unchanged.

Library and personal settings pages now fill the available screen area with host-style gutters instead of fixed centered width caps. Settings headers wrap on narrow screens, including long translated headings.

Targets Jellyfin 12.4.0 on Linux x64. Requires matching Plugin Pages and File Transformation 3.0.3.0 Release-12.4.0 builds. Other server versions, architectures and native clients are not validated. Earlier beta archives remain immutable.
